# 知径 Pathfinder：任意主题与多路径修复说明

> 更新时间：2026-09-13  
> 结论：此前“首发固定为 AI 产品经理”的口径已废止。当前产品以用户自定义学习主题为入口，AI 产品经理仅作为策展模板示例。

## 1. 最新产品合同

1. 用户可以输入任意明确的学习主题，例如 Python 数据分析、摄影、日语口语或产品经理。
2. 路径生成至少使用主题、具体目标、现有基础、每周时间和目标期限五类输入。
3. 用户可以创建多条学习路径；新建路径不得覆盖已有路径、进度和学习资产。
4. 第一条路径是账户主路径；“当前路径”是用户当前正在学习的路径，两者概念分离。
5. 用户切换当前路径后，首页、知识树、节点学习、练习、复习、资料和作品模块应读取同一条路径。
6. 产品经理主题使用经审核的 19 节点教材模板；其他主题由 AI Provider 编排，并诚实标注 Provider、资料来源和不确定性。

## 2. 本轮修复

| 范围 | 修复内容 |
|---|---|
| 产品首页/介绍页 | 主标题改为“你想学什么，AI 就为你生成一条能执行的学习路径”；价值说明改为任意主题与多路径 |
| 路径创建页 | 移除固定主题和固定目标；新增必填主题输入、可选目标、示例主题、四步诊断 |
| 生成过程 | 改为理解目标、检索来源、编排技能、生成个性化路径，不再写死产品经理教材步骤 |
| 路径服务 | 第一条路径为主路径；后续路径创建为非主路径，不再因已有主路径而冲突 |
| 路径列表 | “新建路径”直达完整创建流程；展示主路径与当前路径；非当前路径可一键切换 |
| 跨页状态 | 新创建路径写入 `pf-active-path`；路径列表切换后首页和学习页读取相同路径 ID |
| 演示模式 | 多个主题数据包保存到 `pf-demo-paths`，新建第二条路径不会覆盖第一条 |
| API 模式 | 多条路径分别写入 PostgreSQL，节点、目标、期限和进度独立保存 |

## 3. 数据与交互约束

- `isPrimary`：账户第一条长期主路径；后续创建路径为 `false`。
- `pf-active-path`：浏览器当前选择，用于决定进入哪个主题的学习上下文。
- `pf-demo-paths`：零基础设施演示模式下的多路径数据包集合。
- 生产阶段建议把“当前路径”偏好从 localStorage 同步到用户设置表，以支持跨设备一致性；本轮先保留轻量客户端选择，避免修改已有数据模型。
- 新建路径完成后默认切换到新路径；用户可在“我的学习路径”中切回任意已有路径。

## 5. 后续优化建议

1. 将“当前路径 ID”持久化到服务端用户偏好，支持跨设备同步。
2. 在侧边栏增加轻量路径切换器，减少频繁进入多路径页的操作成本。
3. 路径达到一定数量后提供搜索、置顶、暂停和归档，避免列表膨胀。
4. 对任意主题增加内容质量评测：节点覆盖率、前置关系正确率、来源权威度、资料可访问率和学习者完成率。
5. 在生成前提示“策展模板”和“AI 生成路径”的质量差异，避免用户误解两者具有同等审核强度。
