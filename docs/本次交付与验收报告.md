## 3. 发现的问题与本轮修复

| 问题 | 风险 | DemoZ V2 修复 |
|---|---|---|
| 产品被误固定为 AI 产品经理 | 用户无法按自己的想法创建主题，核心价值被缩窄 | 首页、介绍页、诊断和服务端统一支持任意主题；产品经理改为策展模板之一 |
| 只能创建一条主路径 | 第二个主题返回冲突或覆盖当前体验 | 第一条为主路径，后续路径并行持久化；新增路径入口、当前路径标识和跨页面切换 |
| 原一键登录只切前端角色 | api 模式没有真实身份与数据隔离 | 新增受开关保护的 demo-login、服务端会话和 HttpOnly Cookie |
| AI chat 在 api 模式可匿名调用 | 密钥滥用与成本攻击 | 增加登录校验、请求大小/参数校验、Redis 限流与统一错误信封 |
| Redis 未参与业务 | 无法支撑成本控制与滥用保护 | 接入 AI 与路径预览限流；生产 api 模式 Redis 故障时失败关闭 |
| MinIO 未参与业务 | 文件仅有元数据或假上传 | 完成真实 multipart 上传、MIME/大小限制、失败回滚和短时预签下载 |
| 资料库通用写接口可伪造 objectKey | 可能绕过上传流程访问他人对象 | 禁止客户端写入 upload/objectKey，下载二次校验 owner 与对象前缀 |
| 缺少存活/就绪区分 | 容器编排无法判断依赖状态 | 新增 live 与 ready；ready 分别检查 PostgreSQL、Redis、MinIO |
| 无统一容器部署 | 环境不可复现 | 新增多阶段 Dockerfile 与四服务 Compose、健康检查、迁移和种子 |
| Next.js 版本含高危公告 | 供应链风险 | 升级至 Next.js 16.3.5；生产依赖审计为 0 漏洞 |

| 旧 E2E 文案和流程失真 | 会把正确功能误判为失败 | 改为首发教材流程，修复等待条件、离线文案与令牌扫描误报 |

## 4. 新版产品设计

### 4.1 核心闭环

`任意主题输入 → 目标诊断 → 个性化路径 → 可信证据 → 费曼练习 → 评价与复习 → 技能/作品沉淀`

### 4.2 差异化与微创新

1. 用户意图驱动：主题不是平台固定选项，用户可以直接描述自己真正想学的内容。
2. 策展与生成双轨：产品经理使用审核过的教材骨架，其他主题由 AI 编排并明确来源与不确定性。
3. 多路径不中断：不同主题独立保存，切换当前路径后首页、知识树和学习资产同步变化。
4. 每个节点有 A/B/C 级证据卡：显示来源、推荐理由和可访问性，支持回到依据。
5. 费曼练习不是通用聊天：每次只追一个理解缺口，结果绑定当前节点能力目标。
6. 能力证据代替“AI 打分”：节点、表达、情境和作品共同形成可解释的能力画像。
7. 首页只推荐当前选定路径的一个任务：降低学习者中断后重新选择的认知负担。

### 4.3 技术结构

```text
Browser
  → Next.js App Router（页面 + Route Handler）
      → PostgreSQL / Drizzle：用户、路径、节点、练习、笔记、资料元数据
      → Redis：AI 与路径预览限流
      → MinIO / S3 API：私有文件与短时下载
      → DeepSeek：路径编排、费曼追问、评价
      → Tavily：公开资料检索与证据补充
```

现阶段采用模块化单体，适合 MVP 试点；领域 Service、Provider 和数据表边界为后续拆分留有空间。

## 8. Docker 恢复后的最终验收

本机 Docker Desktop 4.82 在初始化 Inference manager 时无法访问/删除其自身运行目录 `dockerInference`，错误码 1920，导致 Docker daemon 未启动。建议先重启 Windows；若仍失败，使用 Docker Desktop 的 Repair/Reset 前先备份现有 volumes。不要直接删除不明确的 Docker 数据目录。

恢复后在本目录执行：

```powershell
Copy-Item .env.example .env
docker compose up --build -d
docker compose ps
npm run test:e2e:api
```

需补验：

1. 五个角色分别由后端签发会话，并只能读取各自数据。
2. 生成/确认多条任意主题路径后，PostgreSQL 数据可恢复且彼此隔离。
3. AI 与路径接口超过限额时返回 429，Redis 故障时生产 api 模式拒绝请求。
4. 上传文件真实进入 MinIO，本人可下载，其他用户返回 404/403。
5. 重启 app 容器后迁移和种子幂等，已有用户数据不被覆盖。
